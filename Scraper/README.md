# Сборщик малой выборки Авито через gstack

Для нового командного задания начните с
[общего навыка collect-avito](skills/collect-avito/SKILL.md) и
[Aside-процесса](ASIDE_WORKFLOW.md). Ниже сохранена инструкция исторического
Python-сборщика через браузер gstack; это отдельный способ, не команда запуска
Aside. Навык и версия выгрузки фиксируются в паспорте данных.

## Актуальные инструкции от 20.10.2026

Основной проверенный путь для видимой работы агента: [сбор и извлечение через Aside](ASIDE_WORKFLOW.md). Отдельно: [Happ, прямой маршрут Авито и проверка VPN](VPN_HAPP.md). Контрольный результат: пять полных карточек «Разнорабочий» (локальный архив: `../Data/avito_runs/labor_five_2026-10-20/report.md`).

План оптимизации: [распределение работы между JS, Luna low и ведущим](PARALLEL_COLLECTION.md). Это проект конвейера и критерии проверки, не уже реализованный параллельный режим.

Ниже сохранено описание прежнего Python-сборщика и его прогонов 17 октября. Указания «VPN выключен», лимит 1–10, 13 тестов и ограничения извлечения работодателя/адреса относятся к той версии и не являются актуальной инструкцией для Aside. Состояние более поздних расширений Python-сборщика и незавершённого review: PAUSED.md (локальный архив: `../Notes/Research/collector_2026-10-20/PAUSED.md`). Успешный сбор пяти карточек в Aside не подтверждает все возможности этого CLI.

Рабочий путь проверен 17 октября 2026: видимый Chrome gstack → ручная проверка пользователем → отключение VPN пользователем → DOM-сбор. CAPTCHA при включённом VPN проходила, но возвращалось ограничение IP. После отключения VPN в той же браузерной работе появилась выдача. Это наблюдение этой сессии, не универсальная диагностика любой блокировки.

Затем создан **отдельный постоянный профиль сборщика** `Scraper/.gstack/chromium-profile`. После однократной ручной проверки новым профилем получены две карточки. Его процесс штатно остановлен и запущен заново: выдача из 50 строк и две карточки открылись **без повторной CAPTCHA**. Общий браузер T&L не перезапускался, его PID остался прежним. Подтверждение: `Data/avito_runs/restart_verification.json`. Это один реальный цикл перезапуска, не статистическая гарантия длительной работы.

Сборщик использует только стандартную библиотеку Python 3 и уже установленный gstack. Дополнительные библиотеки, расширения, пароли, импорт cookies и изменения SMA Agent не нужны. Прямого HTTP/API-сбора нет.

| `Data/avito_runs/isolated_one_command` | 50 строк | 1 | COMPLETE_SAMPLE: одна команда run с рецептом после перезапуска |

Это 100 наблюдений строк в двух поисках, не 100 уникальных вакансий. Успехи одной сессии не доказывают работу сутками, после перезапуска браузера или с другого IP. Автоматический сбор намеренно ограничен 1–10 карточками за запуск; массовый сбор не выполнялся.

Две основные выборки содержат 100 строк; дополнительные наблюдения при воспроизведении/проверке рецептов не прибавляются к числу уникальных вакансий. Сводная верификация файлов и совпадения фильтров: `Data/avito_runs/verification.json`.

Расширенная проверка всех шести законченных выборок, фильтров выделенного браузера и перезапуска: `Data/avito_runs/reliability_verification.json`. Она подтверждает 11 сохранённых наблюдений полных карточек с повторами, а не 11 разных вакансий. Две CAPTCHA потребовали ручного действия пользователя; это часть наблюдённого процесса, не скрытый автоматический обход.

Сохранены источники и время, зарплатная строка со всеми видимыми уточнениями, все блоки условий/требований, описание, отображаемая дата и просмотры. Из выдачи также сохраняется география. Блок работодателя, контактные лица и точный адрес не сохраняются. Регулярное удаление телефонов/email в описании ограничено типовыми форматами; универсальная анонимизация не заявляется.

В `general_01/conflicts.json` автоматически найден кандидат конфликта: ежедневные выплаты в тексте против еженедельных в поле. Это ограниченное правило, не полная проверка всех смысловых конфликтов. Истинное значение не выбирается.

## Использование

Команды выполняются из корня T&L:

Рекомендуемый запуск одной командой, с отдельным браузером и сохранением профиля:

```sh
python3 Scraper/avito.py run --isolated --output Data/avito_runs/my_first_sample --limit 3 --delay 8
```

Каждому новому заданию нужен отдельный output. При появлении CAPTCHA сбор останавливается; её проходит пользователь в видимом окне. Содержимое профиля не копируется из Safari/общего Chrome, не выводится в чат и не входит в результаты. `Scraper/.gitignore` исключает каталог браузера из будущего Git-репозитория. Временный сетевой доступ после проверки не гарантирует сохранение допуска на другом IP.

Управление только своим экземпляром:

```sh
python3 Scraper/avito.py status --isolated
python3 Scraper/avito.py stop --isolated
```

`stop` без `--isolated` запрещён, чтобы не закрыть общий браузер проекта. Следующий `run --isolated` использует тот же постоянный профиль. Одновременная вторая команда сборщика для этого экземпляра отклоняется файловой блокировкой; при завершении процесса блокировка снимается ОС.

Ниже сохранены низкоуровневые команды для управления вручную и первоначальной общей сессией. Для выделенного экземпляра к каждой из них добавляется `--isolated`:

```sh
python3 Scraper/avito.py open --url https://www.avito.ru/all/vakansii --handoff
```

При ручном переходе gstack в видимый Chrome ID вкладки может измениться. После `browse resume` нужно определить ID именно вкладки сборщика; не использовать произвольную активную вкладку. Значение `--tab-id` ниже заменить актуальным ID. На текущем запуске пользовательская вкладка после handoff получила ID 39.

```sh
python3 Scraper/avito.py inspect --tab-id 39
python3 Scraper/avito.py collect --tab-id 39 --url 'https://www.avito.ru/all/vakansii#block' --output Data/avito_runs/new_sample --limit 3 --delay 8
```

URL берётся из фактической страницы. Полный переданный URL сохраняется; допускаются только наблюдённые безвредные различия: служебный context, fragment и удаление localPriority=0. Параметр f и остальные параметры не отбрасываются. URL объявления проверяется, сбор с другого домена запрещён.

Каждая карточка и manifest пишутся атомарно. После ошибки/CAPTCHA данные завершённых карточек сохранены. CAPTCHA не повторяется автоматически, underlying DOM под окном ограничения не извлекается. После ручного восстановления страницы:

```sh
python3 Scraper/avito.py collect --tab-id 39 --url 'https://www.avito.ru/all/vakansii#block' --output Data/avito_runs/new_sample --resume --delay 8
```

Resume читает вручную восстановленную незавершённую карточку без повторной навигации. При уже завершённой выборке не загружает карточки повторно. Это проверено тестом остановки между карточками и живым повтором завершённого прогона. Также выполнено реальное продолжение прогона выделенного профиля после CAPTCHA на начальной выдаче. Если после перезапуска изменился tab_id, передать новый ID: сборщик проверит совпадение поиска или ID незавершённой карточки перед привязкой. Профили общего/выделенного браузера нельзя смешивать при resume.

Код возврата 0 означает COMPLETE_SAMPLE; 2 — требуется действие/карточка не подтверждена, 1 — ошибка. COMPLETE_SAMPLE относится к выбранному лимиту, не ко всей выдаче. Пустая/непонятная страница не считается успешным нулевым результатом.

## Фильтры

Проверенные условия пользовательской ссылки: Москва, профессия Упаковщик, «Работа до 17:00», «Сначала из Москвы» выключено.

Установка этих фильтров и сбор карточек одной командой:

```sh
python3 Scraper/avito.py run --isolated --recipe Scraper/moscow_packers_before17.json --output Data/avito_runs/my_packers_sample --limit 3 --delay 8
```

```sh
python3 Scraper/avito.py filters --recipe Scraper/moscow_packers_before17.json --output Data/avito_runs/new_filter
```

Команда открывает обычный `/moskva/vakansii`, нажимает только проверенные элементы поиска и проверяет итоговые состояния всех элементов. Неподтверждённый/изменившийся элемент останавливает выполнение. В первом запуске верификатор не принимал роль `switch` у локального приоритета; UI уже выставил нужные условия, проверка была исправлена и повторена на той же вкладке. Итоговый f совпал с исходной ссылкой; context новый.

В `filters.json` сохраняются новый URL, фактические фильтры и наблюдения выдачи. Далее этот URL и tab_id можно передать `collect`. Другие рецепты/города надо проверять отдельно: универсальный подбор любых фильтров не заявляется. Фильтр Авито означает принадлежность поисковой выдаче, а не доказанную правдивость условий работодателя; нельзя подменять им анализ описания.

## Проверка

```sh
python3 -m unittest discover -s Scraper -v
```

13 тестов: восемь первоначальных проверок URL, остановки, полноты карточек, конфликта, checkpoint/resume и клика; ещё пять проверяют изоляцию профиля, новую привязку вкладки после перезапуска, запрет смены сегмента после CAPTCHA, запрет смешения профилей и взаимоисключение одновременных команд. Дополнительно `extract.js` проверен в реальном Chromium на локальных фикстурах `fixtures/`: блокирующий оверлей поверх карточки даёт NEEDS_HUMAN и пустой список, обычная выдача сохраняет зарплату за смену и выбранный фильтр. Это тестовые данные, не живые вакансии.

Третья DOM-фикстура проверяет двоеточие внутри названия: «Можно заканчивать в 17:00: Да» должно давать имя «Можно заканчивать в 17:00» и значение «Да». Сбой обнаружен при проверке живой карточки; разделение по первому двоеточию заменено на разделитель «двоеточие + пробел». Производные fields в сохранённых живых файлах пересчитаны из неизменённых params_blocks, версия разбора 2. Отсутствие «на руки» в двух карточках фильтрованного поиска сохранено как отсутствие уточнения, не считается ошибкой и не дополняется предположением.

Дополнительная живая проверка нового запуска (`recreated_filter_fresh`) выявила потерю раннего клика: состояние профессии оставалось false и URL не изменялся. Причина предположительно в гидратации/готовности обработчиков страницы, точный внутренний механизм не инструментировался. Добавлены опрос фактического состояния и максимум два клика только пока значение не подтверждено; при CAPTCHA повтор запрещён. Следующий новый запуск `recreated_filter_fresh_02` прошёл полностью. Это устранение конкретного наблюдённого сбоя, не гарантия отсутствия остальных.

## Что не гарантируется

Не гарантируются работа сутками, все возможные шаблоны Авито, долговечность DOM-селекторов, доступ с другого IP/после перезагрузки компьютера и исчерпывающая проверка конфликтов. Восстановление после одного штатного перезапуска браузера подтверждено. Рабочий режим: выделенный видимый gstack с постоянным профилем, VPN выключен, небольшие последовательные выборки, ручное восстановление при новой проверке сайта. Абсолютно безотказным или промышленным сборщиком этот результат не называется.
