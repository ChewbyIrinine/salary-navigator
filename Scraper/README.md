# Сбор данных через агента

Командный способ сбора — агент, который использует
[collect-avito](skills/collect-avito/SKILL.md), gstack `/browse` и **Aside**.
Он работает с видимыми страницами: задаёт фильтры, сохраняет очередь,
читает карточки и готовит выгрузку для анализа.

## Подготовка рабочего места

Нужны Python 3.10+, установленный для агента gstack `/browse`, приложение
Aside и его CLI. Для текущего Aside-процесса нужна поддерживаемая приложением
macOS; инструкции установки берите из самого приложения и актуального `/browse`.
Проектный навык доступен по пути `Scraper/skills/collect-avito/SKILL.md`:
достаточно указать его агенту вместе с заданием. Наличие файла в репозитории
не означает, что навык уже установлен в личный каталог каждого участника.

Один раз создайте **локальный**, исключённый из Git файл настроек:

```sh
cp Scraper/collect-avito.config.example.json Scraper/collect-avito.local.json
```

Заполните его под свою среду:

- Без туннеля: `"tunnel_mode": "disabled"`, `"xray_config_path": null`.
- С Happ/Xray: `"tunnel_mode": "xray"`, `"xray_config_path"` — абсолютный путь
  к актуальной полной JSON-конфигурации **вне репозитория**.
  Можно использовать `~/…`. Полный конфиг содержит секреты и остаётся локально.
  Другой VPN-клиент требует отдельной проверки маршрута: не называйте его Xray.

Для Happ нужны прямые правила `avito.ru` и `avito.st`, включая поддомены.
Как настроить и проверить их применение — в [VPN_HAPP.md](VPN_HAPP.md).
Скрипт читает выбранный файл и выводит только результат проверки правил.
Сам туннель, профиль и сетевые настройки он не меняет.

## Перед каждым сбором и после обновления репозитория

```sh
python3 Scraper/skills/collect-avito/scripts/preflight.py --probe-aside
```

Проверка повторяется целиком: Python, файлы проекта, наличие `/browse`,
Aside CLI и доступность REPL, локальные настройки и правила Xray, если он выбран.
Открывать сайт или менять вкладки для этой проверки не требуется.
Без `--probe-aside` проверяются только локальные зависимости и конфигурация.
Для машиночитаемого результата добавьте `--json`; для другого локального файла —
`--config /абсолютный/путь.json`.

При проблеме скрипт выводит `NEEDS_SETUP`, конкретную подсказку и код возврата 2.
После исправления запускайте ту же команду: готовность не кешируется, поэтому
смена конфигурации или обновление файлов будут проверены заново.
`LOCAL_CHECKS_OK` означает успешность локальных проверок. Подключение
работающего туннеля к этому конфигу и доступ к Авито подтверждает агент
при первой обычной загрузке по [процедуре](VPN_HAPP.md).

## Как поставить задание

Укажите агенту:

- ссылку на задачу/исследование в Buildin;
- географию, профессию и остальные фильтры;
- способ отбора: первые N выдачи или N подходящих по явному правилу;
- лимиты просмотра и сохранения, нужные поля;
- новый каталог в `Data/avito_runs/` или checkpoint незавершённого сбора.

Пример задания — в [корневом README](../README.md#если-нужны-данные).
Агент читает навык, запускает preflight, проверяет, свободен ли поток Авито,
и только затем начинает работу. После смены города перепроверяет профессию
и остальные контролы. Перед каждой навигацией сохраняет состояние, а после
чтения карточки — исходные данные и свидетельства. Подробные действия
интерфейса и правила разбора — в [ASIDE_WORKFLOW.md](ASIDE_WORKFLOW.md).

При CAPTCHA или ограничении доступа агент сохраняет состояние и останавливается.
Продолжение начинается с checkpoint и проверки текущей страницы;
ранее сохранённые карточки не нужно открывать заново. У завершённой выгрузки
продолжения нет: следующий сбор создаёт новый каталог.

## Что передаём команде

Экспорт содержит таблицы для анализа, паспорт, план и ограничения отбора.
Исходные карточки позволяют проверить происхождение значений. Экспорт строится
из сохранённых данных: повторный запуск обработки не должен открывать сайт.
Конкретные правила обработки и её версия фиксируются вместе с результатом.

[Data/README.md](../Data/README.md) объясняет состав таблиц и версионирование,
а [ML/README.md](../ML/README.md) — как загрузить данные и закрепить их в эксперименте.
Универсального экспортёра для всех схем пока нет: агент готовит экспорт
по согласованной схеме и проверяет его перед передачей.
