# Первый запуск: от GitHub до CSV

Это инструкция агенту, который впервые получил `collect-avito`. Пройдите путь
до проверенного CSV; отсутствие окружения означает следующий шаг настройки,
а не конец задания. Сохраняйте уже выполненные шаги и продолжайте после действий
участника. Повторный сбор в готовом окружении не требует повторной установки.

## 1. Получить проект и выбрать исполнителя

Скачайте весь [salary-navigator](https://github.com/tooscl/salary-navigator)
(Code → Download ZIP и распаковка либо clone). Откройте папку проекта в агенте
с доступом к локальным файлам и терминалу. Один `SKILL.md` не содержит экстрактор,
контракт CSV и утилиты. Изолируйте рабочую копию, если другой агент пишет в неё.

Участнику достаточно такого задания:

> Используй Scraper/skills/collect-avito/SKILL.md. Помоги подготовить окружение
> с нуля и собери первые 3 уникальные вакансии общей выдачи всех регионов без
> запроса и фильтра профессии. Сохрани полный текст, все характеристики и
> расположение в CSV. Это локальная проверка, без публикации в GitHub.

Codex и Claude Code могут читать этот файл непосредственно из проекта;
личная установка `collect-avito` не обязательна. Для другого агента нужны
чтение файлов, запуск Python и доступ к gstack `/browse`/Aside CLI. Не объявляйте
совместимость с конкретным приложением без реального запуска. Облачный чат
без локального исполнителя этот процесс сам не выполняет.

## 2. Проверить и подготовить инструменты

Проверьте ОС, Python, `aside --help` и наличие gstack `/browse`. На macOS/Linux
интерпретатор обычно `python3`, на Windows — `py -3` или `python`. Во всех
командах ниже заменяйте `python3` на найденную команду, версия нужна 3.10+.

Если Python отсутствует, помогите установить его по
[официальной инструкции Python](https://www.python.org/downloads/), затем
проверьте версию в новом терминале. У скриптов подготовки и экспорта нет
сторонних Python-зависимостей; pandas нужен только для анализа готового CSV.

Если gstack отсутствует, откройте [официальный репозиторий gstack](https://github.com/garrytan/gstack)
через `/browse` и следуйте его актуальному Install для выбранного агента/ОС.
Если `/browse` ещё нет, дайте ссылку участнику для ручной установки;
не обходите правило проекта другим агентным веб-инструментом.
Официальная инструкция требует Git и Bun (рекомендуемая версия 1.4.2+),
на Windows также Node.js и Git Bash. Для Codex используется `./setup --host codex`
из каталога скачанного gstack, для Claude Code — `./setup`. На Windows
PowerShell-вариант `./setup.ps1` принимает те же аргументы и подсказывает
недостающие зависимости. Проверяйте актуальные требования производителя,
не отключайте системную защиту ради запуска. Не копируйте конфигурацию автора.
Не представляйте наличие `SKILL.md` как доказательство работоспособности браузера.

Установите [Aside](https://aside.com/download) для ОС участника и откройте
приложение. Страница производителя предлагает macOS и Windows; Linux-процесс
и Windows-проход до CSV в проекте ещё не подтверждены. Следуйте текущей инструкции
Aside для установки CLI: не угадывайте установочные команды. Затем проверьте
`aside --help`. Если команда не найдена, проверьте PATH/установку CLI и откройте
новый терминал. Не подменяйте ошибку установки запуском старого `avito.py`.

При ошибке авторизации прочитайте `aside login --help` и помогите участнику
подтвердить CLI в приложении. Пароли и коды участник вводит сам. При нескольких
host/profile проверьте выбор через документированные команды `aside host`.
Вход в аккаунт Авито проверяется в собственной сессии; авторизация автора
проекта не переносится. Cookies, профили и приватные логи не копируются.

Проверяйте успешность каждого шага перед следующим. Если установка требует
системного разрешения или входа, дайте участнику конкретное действие и после
его выполнения повторите проверку; не заявляйте автоматическую установку.

## 3. Создать локальные настройки

Режим берите из задания/подтверждённого окружения. Если он неизвестен, спросите
один раз: без VPN, Happ или другой клиент? Не выбирайте `disabled` только из-за
отсутствующего конфига. При запросе настроить Happ сразу готовьте вариант Happ.

Без VPN:

```sh
python3 Scraper/skills/collect-avito/scripts/setup_workspace.py --mode disabled
```

С Happ:

```sh
python3 Scraper/skills/collect-avito/scripts/setup_workspace.py --mode happ
```

Скрипт создаёт `Scraper/collect-avito.local.json`, а для Happ ещё JSON-профиль
и `avito-routing-link.txt` вне checkout. Путь напечатан в результате. Файлы
повторно не перезаписываются: совпадающий запуск безопасен, изменённые настройки
нужно сохранить и выбрать новый `--config`/`--state-dir`. На Windows внешний
каталог по умолчанию находится в LOCALAPPDATA, на macOS/Linux в XDG_DATA_HOME
или `~/.local/share/tl-avito`. Можно выбрать `--state-dir` вне checkout явно.

Для уже имеющегося полного Xray JSON:

```sh
python3 Scraper/skills/collect-avito/scripts/setup_workspace.py --mode xray --xray-config /absolute/private/config.json
```

Это проверка и ссылка на существующий файл, не изменение подписки. Другой
VPN-клиент требует его собственной процедуры; не называйте его Xray/Happ.

Если `/browse` установлен в другом месте, добавьте к выбранной команде
`--browse-skill /absolute/path/to/gstack/browse/SKILL.md`. Скрипт запомнит путь
в локальном конфиге. Для временной проверки поддерживается `TL_BROWSE_SKILL`.
Общий конфиг для нескольких checkout передаётся через `TL_AVITO_CONFIG` или
`--config`; аргумент должен использоваться и при подготовке, и при preflight.

## 4. Импортировать Happ

Откройте [VPN_HAPP.md](../../../VPN_HAPP.md), раздел «Создать профиль для импорта».
Покажите участнику готовый `avito-routing-link.txt` и объясните действие:
импортировать в Happ и выбрать профиль у своей подписки. Это не VPN-подписка:
сервер/подписка должны быть у участника. Не запрашивайте их секреты в чате.
Не открывайте автоматически deeplink и не перезапускайте общий туннель.

## 5. Подтвердить готовность и собрать пробу

```sh
python3 Scraper/skills/collect-avito/scripts/preflight.py --probe-aside
```

При `NEEDS_SETUP` устраните указанную зависимость по разделу 2 и повторите.
При `READY_WITH_WARNINGS` можно проверить первую обычную загрузку сайта;
маршрут без независимого измерения остаётся неподтверждённым. Для отдельной
проверки файла маршрутизации добавьте `--strict-routing`: она не доказывает
импорт/активацию профиля или отсутствие CAPTCHA.

Дальше выполните основной SKILL.md: собственная сессия, подтверждение фильтров,
замороженная очередь, raw JSON каждой карточки и checkpoint. Малой проверки на
3 карточках достаточно для первого запуска. При CAPTCHA сохраните checkpoint,
не создавайте дополнительные профили и не меняйте IP ради продолжения.

## 6. Получить CSV

Сначала проверьте каждую карточку и её расположение по snapshot. Создайте
локальный `review.json`, где каждый ключ — принятый ID, например:

```json
{
  "1234567890": {
    "reviewed": true,
    "city": "Москва",
    "profession": "",
    "segments": "all_regions_no_profession",
    "listing_rank": 1,
    "listing_promoted": true
  }
}
```

Значения здесь — пример, не данные для нового сбора. Заполняйте только
наблюдённые сведения. Город — размещение на сайте, не slug URL и не место
работы из описания. `full_parameters_read` остаётся false, если полнота
отдельно не подтверждена. Каждая карточка в `raw/` называется `<ID>.json`.

```sh
python3 Scraper/skills/collect-avito/scripts/export_captures.py --raw-dir Data/avito_runs/<run_id>/raw --review Scraper/runs/<run_id>/diagnostics/review.json --output Data/avito_runs/<run_id>/exports/vacancies_flat.csv
```

Экспортёр проверяет ID, описания и наличие расположения, сохраняет все пары
характеристик отдельными колонками и не перезаписывает существующий CSV.
Он не заменяет проверку отбора агентом. Проверьте CSV через `csv.DictReader`
или `pd.read_csv`, число уникальных ID и сохранность текстов. Завершите паспорт,
план и каталог данных. При обычном командном сборе следуйте основному навыку
для обновления общей таблицы и PR; локальная проба не публикуется автоматически.

Готовность означает: повторный preflight разрешает сбор, реальные карточки
прочитаны и CSV открывается. Список установленных программ сам по себе этого
не доказывает. В отчёте укажите ОС и непроверенные платформы.
