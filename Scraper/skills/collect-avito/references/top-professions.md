## Как использовать в сборе

- «По топ-профессиям», «по нашим топ-20» означают именно этот рабочий список.
  Не стройте новый рейтинг и не заменяйте его популярными тегами страницы.
  Явно названная профессия/запрос/сбор без профессии имеют приоритет. Если охват
  неясен, предложите рабочий список и уточните его до обхода. Не считайте число
  вакансий числом профессий: «10 удалённых вакансий» не означает 10 профессий.
- Формат, выбранный участником 28.10.2026 в TL Demo 6: одновременно отметить
  **все 20** профессий списка в одном фильтре и взять **первые N уникальных
  карточек общей выдачи**, по наблюдённому порядку, без квот на профессию.
  При следующих запросах по топ-профессиям предлагайте этот формат. N — общий
  объём, не N×20. «Все профессии» здесь означает наши 20, не весь каталог.
  Отдельные срезы и квоты используются только по явному заданию участника.
- До обхода подтвердите географию/общий лимит/сортировку; не спрашивайте заново
  уже выбранный формат. Перед freeze сверьте набор всех 20 name/value, отсутствие
  посторонних выбранных профессий и фактический URL. site_value — историческая
  подсказка для UI, URL из кодировки не конструируется. profession в плане/CSV
  сохраняет весь набор выбранных фильтров; это не определение профессии вакансии
  по её названию. Не приписывайте объявлению один из 20 фильтров по догадке.
- Общая выдача получает одну очередь/run_id и checkpoint. Если N больше числа
  карточек на странице, используйте только проверенную готовую пагинацию.
  В текущем runner она не реализована: не выдавайте поддержку 200 карточек за
  проверенную и не пишите одноразовый обход. Сначала подготовьте общий код,
  тест и обновлённую инструкцию по поручению на такой сбор; не заменяйте задачу
  двадцатью отдельными срезами и не придумывайте URL следующих страниц.
- Один браузерный агент последовательно исполняет пакеты, Terra подключается
  один раз после всего задания для проверки и публикации, по ходу — при ошибках.
  При явно заданных отдельных run_id финализируйте/публикуйте их последовательно,
  не оставляя в общем реестре ссылок на ещё не отправленные исходники.
- Историческое отсутствие фильтра «Военный» в списке не означает удаления
  военных объявлений из выбранных профессий: такие строки сохраняются с
  техническим military по словарю названия. Пропуски характеристик не меняют
  очередь и не запускают добор. Новый актуальный рейтинг — отдельное исследование.
