# Экспорт вакансий

[Описание всех файлов и колонок](../../../README.md#что-лежит-в-exports-первой-выгрузки).

Для анализа начните с [vacancies_flat.csv](vacancies_flat.csv).
`vacancies.csv` и `vacancies.json` — подробные собранные вакансии в двух форматах,
а не текстовый отчёт агента. Остальные общие таблицы описывают срезы,
характеристики и их заполненность.

В соседнем `raw/` каждая прочитанная вакансия хранится отдельным JSON-объектом;
в `cards/` — карточки после проверки. В экспорте они объединены для работы
с выборкой целиком.
