# Первые пять курьерских вакансий, Москва, 26 октября 2026

Собраны последовательно первые пять уникальных объявлений в порядке выдачи.
Выбраны Москва и точный checkbox «Курьер», остальные контролы оставлены по
умолчанию. Вход через популярную ссылку «Курьер» сохранил в URL `tag/kurer`;
это зафиксированный способ отбора, не общая выдача без тега.
Все пять объявлений продвинутые; неудобные строки не заменялись следующими.

Основной результат — [CSV из пяти строк](exports/vacancies_flat.csv).
Он зарегистрирован в общей таблице: **238 + 5 = 243 уникальные вакансии**,
пересечений с предыдущей выгрузкой нет. Общая схема выросла с 64 до 66 колонок:
`listing_rank` и `listing_promoted`. Все найденные параметры карточек вынесены
в отдельные колонки, новые строки содержат 10–17 параметров каждая.

Зарплаты сохранены без предположения о месячном периоде. Описания содержат
дополнительные ставки и условия; они сохранены полностью. Обогащение для
этого эксперимента не запускалось: `enrichment_status=not_run`.
География соответствует размещению на сайте; расположение карточки сохранено
отдельно. Generic-экстрактор не прочитал блок расположения: он дополнен из
сохранённого snapshot, а не из описания. Неоднозначные токены `values`
не использовались: в CSV попали полные исходные значения параметров.

`raw/` — неизменённый результат экстрактора; `cards/` — проверенные строки
и наблюдённые ссылки работодателей; `evidence/` — исходная выдача, очередь,
snapshot фильтров/карточек и настоящие viewport-скриншоты. Профили работодателей
и контакты не открывались. Screenshot не является снимком всей карточки.
План и [паспорт](../../../Scraper/runs/courier_first5_2026-10-26/manifest.json)
содержат версии, временной диапазон, ограничения и SHA-256 файлов.

`prepare_export.py` воспроизводит только этот проверенный экспорт офлайн
из raw и свидетельств. Завершённые файлы он не перезаписывает: для повторной
проверки используйте временную копию без готовых cards/*.json и exports/CSV
(сохраните cards/*.public.json). Общий CSV собирается обычной командой
`python3 utils/build_dataset.py`, без отдельного кода объединения для этого сбора.

Доступ к Авито работал, CAPTCHA не было. Preflight подтвердил Aside, но
локальный файл режима подключения отсутствовал. Продолжили по прямому
подтверждению пользователя, что конфигурация работает. Независимая проверка
активного сетевого маршрута не выполнялась. Ожидание первого popup завершилось
тайм-аутом после фактического открытия; карточка найдена по ID без повторного клика.
