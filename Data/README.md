# Датасеты

Здесь хранятся готовые выгрузки CSV/JSON. Для анализа достаточно одного CSV:
скачайте его или откройте из репозитория через `pd.read_csv(...)`.
Дата в названии — дата наблюдения, а не дата коммита.

## Доступные наборы

| Набор | Срез и время | Назначение |
|---|---|---|
| [Первая выгрузка — один CSV](first_export_2026-10-21.csv) | 6 профессий, Москва/СПб/Екатеринбург; 21.10.2026 МСК | 238 уникальных вакансий; одна строка на вакансию, параметры в отдельных колонках |

Эта выборка не является репрезентативной оценкой рынка или готовой разметкой
«рыночной зарплаты». Ограничения отбора и неизвестные значения сохранены в данных.

## Сразу получить DataFrame

Из корня репозитория, с установленным `pandas`:

```python
import pandas as pd

df = pd.read_csv("Data/first_export_2026-10-21.csv", dtype={"id": "string"})
df.head()
```

Файл самодостаточен: для чтения не нужны карточки, паспорт или загрузчик.
[Ноутбук с примерами](../ML/00_load_first_export.ipynb) показывает просмотр
колонок, фильтрацию и подсчёт вакансий по городам.

| Колонки | Содержимое |
|---|---|
| `id`, `title`, `source_url`, `observed_at` | ID, заголовок, ссылка и время чтения карточки в UTC |
| `city`, `profession`, `segments` | Город и сегменты отбора. Несколько значений разделены `; ` |
| `salary_raw`, `description` | Зарплатная строка и полное сохранённое описание без пересчёта сумм |
| `employer_name_observed`, `location_observed` | Наблюдавшиеся имя работодателя и расположение |
| `График`, `Занятость`, `Опыт работы` и другие | Все 32 параметра карточек, каждый в своей колонке |
| `full_parameters_read`, `read_status_*`, `read_limitations` | Что удалось прочитать и ограничения чтения |

Пустая ячейка означает отсутствие сохранённого значения, а не ноль или «нет».
Две вакансии попали одновременно в «Продавец» и «Кассир»: в `profession`
сохранены оба значения, строки не дублируются. Поэтому вакансий 238,
а включений в сегменты — 240. При сравнении сегментов используйте `segments`;
обычный `value_counts()` по `profession` считает сочетания профессий.

## Как добавить набор

1. Согласуйте срез, фильтры, режим отбора, лимиты и поля в исходной задаче.
2. Попросите агента выполнить [collect-avito](../Scraper/skills/collect-avito/SKILL.md)
   с новым каталогом `Data/avito_runs/<дата>_<срез>_<номер>/`.
3. Подготовьте **один самодостаточный CSV**: одна строка на вакансию, поля
   карточки в отдельных колонках, без обязательного разбора JSON при чтении.
   Добавьте его в каталог выше. Сохраните план, исходные наблюдения и результат
   проверки. Экспорт CSV/JSON
   формируется из сохранённых карточек; он не должен незаметно запускать новый сбор.
4. Заполните [паспорт](manifest.template.json): dataset_id/run_id, время,
   фактические фильтры, схема, версии кода и инструкции, план/факт, ошибки,
   ограничения и файлы с SHA-256. Шаблон задаёт метаданные; это не команда экспорта.
   Для совместимости с загрузчиком образцом служит паспорт существующего набора.
5. Проверьте таблицы и принятые включения. Добавьте набор в каталог выше,
   а ссылки на результат — в задачу и исследование Buildin.

Завершённый набор сохраняется неизменным. Новый сбор получает новый run_id,
изменение полей — новую версию схемы, переработанный экспорт — новый dataset_id
со ссылкой на источник. Для анализа выбирайте конкретный CSV; в сохраняемом
эксперименте фиксируйте его путь и SHA-256. Паспорт нужен для подробной проверки
происхождения, а не для открытия таблицы.

В общий Git входят данные и необходимые свидетельства происхождения.
Cookies, браузерные профили, приватные журналы сессий и настройки подключения
в него не включаются.
