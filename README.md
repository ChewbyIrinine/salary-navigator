# T&L — Авито Работа: Навигатор зарплат

Общий Git содержит три рабочих раздела:

| Раздел | Что хранится |
|---|---|
| [Data/](Data/README.md) | CSV/JSON выгрузки, дата и срез, паспорт и версия состава полей |
| [ML/](ML/README.md) | ноутбуки, подготовка/обучение, эксперименты и модели; общие функции в [ML/utils/](ML/utils/) |
| [Scraper/](Scraper/README.md) | код и инструкции сбора, [общий навык агента](Scraper/skills/collect-avito/SKILL.md) |

Исследования, источники и рабочие договорённости — в Buildin:

В первой выгрузке — 238 уникальных вакансий, 240 включений в 18 срезов.
[Notebook загрузки](ML/00_load_first_export.ipynb) закрепляет паспорт и проверяет
SHA-256 файлов. Даты наблюдения, поля и ограничения указаны в
[паспорте](Data/first_export_2026-10-21.manifest.json),
[закреплённый план отбора](Data/first_export_2026-10-21.plan.json) хранится рядом.
Завершённые данные не перезаписываем; новую версию подключаем явно.

Проверка загрузки из корня проекта:

```sh
python3 ML/utils/load_dataset.py Data/first_export_2026-10-21.manifest.json
```

Структура уточнена 22.10.2026 МСК. Общий репозиторий:
[tooscl/salary-navigator](https://github.com/tooscl/salary-navigator).

Notes/ не входит в опубликованный состав. Инструкции передачи и аудит
хранятся отдельно от общего репозитория.
