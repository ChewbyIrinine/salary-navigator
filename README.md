# T&L · Навигатор зарплат

Это общее пространство команды для данных и моделей. Здесь можно взять
готовую выгрузку вакансий, получить новую, провести анализ и сохранить модель.
Задачи и исследования находятся в [Buildin](https://buildin.ai/e1d7c3f7-5ae9-4537-993a-f1a84e552025).

## Как устроено пространство

| Папка | Что внутри |
|---|---|
| [Data/](Data/README.md) | Готовые выгрузки и описание их состава: дата, города, профессии и поля |
| [ML/](ML/README.md) | Ноутбуки для анализа и обучения |
| [ML/utils/](ML/utils/) | Общие функции: загрузка данных и подготовка таблиц |
| [ML/experiments/](ML/experiments/README.md) | Результаты экспериментов и сравнения моделей |
| [ML/models/](ML/models/README.md) | Сохранённые модели и код их применения |
| [Scraper/](Scraper/README.md) | Навык агента, извлечение данных и проверка окружения перед сбором |

В [каталоге данных](Data/README.md) перечислены доступные выгрузки.
Основной файл каждой выгрузки — **CSV, который можно сразу открыть как таблицу**.
Исходные карточки и технические сведения о сборе нужны для подробной проверки;
для начала анализа их разбирать не требуется.

## Как получить новую выгрузку

Дайте агенту задание и укажите [навык сбора](Scraper/skills/collect-avito/SKILL.md).
Напишите, какие нужны профессии и города, фильтры, число вакансий и поля.
Если выборка нужна для конкретной задачи, добавьте ссылку на неё.

Например:

> Используй Scraper/skills/collect-avito/SKILL.md. Собери первые 10 уникальных
> вакансий курьера в Москве без дополнительных фильтров. Сохрани параметры,
> описание и дату наблюдения. Подготовь один CSV, который можно сразу открыть
> в pandas, и короткое описание состава выгрузки.

Агент проверит окружение, откроет Aside через gstack /browse, применит фильтры,
прочитает карточки и соберёт таблицу. При ограничении доступа сохранит место
остановки. Подготовка Aside и туннеля описана в [Scraper/README.md](Scraper/README.md).

На выходе нужны ссылка на готовый CSV и описание: что собрали, когда,
какие поля доступны и что прочитать не удалось. Новая выгрузка появляется
в [каталоге Data](Data/README.md).

## Как работать с готовой выгрузкой

1. Выберите набор в [каталоге данных](Data/README.md).
2. Скачайте его CSV или откройте файл прямо из локального репозитория.
3. Для начала анализа используйте [ноутбук с примерами](ML/00_load_first_export.ipynb).
   Для его запуска сохраните папки `Data/` и `ML/` рядом, как в репозитории.

Пример чтения существующей выгрузки из корня проекта:

```python
import pandas as pd

df = pd.read_csv("Data/first_export_2026-10-21.csv", dtype={"id": "string"})
df.head()
```

В этой таблице одна строка — одна уникальная вакансия, характеристики вынесены
в отдельные колонки. Значения и ограничения описаны в [Data/README.md](Data/README.md).

Свой анализ сохраняйте в ноутбуке в `ML/`. Повторно используемые функции
можно вынести в `ML/utils/`, результаты эксперимента — в `ML/experiments/`,
обученную модель — в `ML/models/`. Примеры работы с ними — в [ML/README.md](ML/README.md).
